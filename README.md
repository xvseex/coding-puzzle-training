# Coding Puzzle Training

Practice repo building toward an AI-training coding puzzle solver role. 
Solving problems in both Python and C++, following a structured roadmap covering data 
structures, algorithmic patterns, debugging, and reproducible engineering practices. 

## Week 1 - SYntax Foundations
- 'week01/basics.py' - variables, conditionals, loops
- 'week01/fizzbuzz.py' - FizzBuzz
- 'week01/palindrome.py' - palindrom checker
- 'week01/array_reversal.py' - manual array reversal (no built-ins)
